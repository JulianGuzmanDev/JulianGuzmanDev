## 🚀 Proyectos destacados

### [CVcraft](https://github.com/JulianGuzmanDev/cvcraft) — Generador de CVs con IA
Optimizá tu CV para una oferta laboral específica usando inteligencia artificial.  
Subí tu CV existente o completá un formulario → obtenés un PDF adaptado al puesto en segundos.  
**Stack:** Next.js · TypeScript · Supabase · Groq (Llama 3.3 70b) · React PDF  
🔗 [Demo en vivo](https://cvcraft-seven.vercel.app)

---

### [Inkwell](https://github.com/JulianGuzmanDev/inkwell) — Plataforma de blog con roles y permisos
Flujo editorial completo con roles de Admin, Editor, Autor y Lector.  
Permisos implementados con Row Level Security en Supabase: la seguridad vive en la base de datos, no solo en el frontend.  
**Stack:** Next.js · TypeScript · Supabase (Auth + PostgreSQL + RLS) · Groq  
🔗 [Demo en vivo](https://inkwell-rust-eight.vercel.app)

---

### [Quill](https://github.com/JulianGuzmanDev/quill) — Bloc de notas con IA
Editor de notas con funciones de IA para resumir, reescribir y generar contenido.  
Auth con Google y Magic Link, guardado automático, diseño oscuro.  
**Stack:** Next.js · TypeScript · Supabase · Groq (Llama 3.3 70b)  
🔗 [Demo en vivo](https://quill-zeta-two.vercel.app)
